# Forex Analyzer

Spring Boot приложение для анализа валютных пар. Показывает RSI (индекс относительной силы), текущую цену, уровни поддержки/сопротивления, торговые сигналы перекупленности/перепроданности и историческую волатильность (ATR).
Данные поступают в реальном времени из **MetaTrader 5** через **ZeroMQ**.

Отправка сигналов в реальном времени осуществляется в канал в MAX
[Forex Analyzer](https://max.ru/https://max.ru/join/zJL-LeCnX38NrkO3CoDuytA00-UbabHpsWJH0Z_hOFw).

## Стек технологий

- **Java 21**
- **Spring Boot 4.0.8** (Web, Data JPA, Scheduling)
- **PostgreSQL** (в облаке Supabase)
- **ta4j 0.15** — библиотека технического анализа
- **ZeroMQ (jeromq)** — приём тиков и свечей из MT5
- **[Swagger / OpenAPI 3](http://185.209.30.192:8080/swagger-ui.html)** — интерактивная автодокументация API (Кликните для перехода)
- **Maven**

## Архитектура

```
MT5 (VPS) → MQL5-советник → ZeroMQ → Java (Spring Boot) → Supabase
                                              ↓
                                         REST API
                                              ↓
                                     Android / браузер
```

- **`MQL5-советник`** — отправляет тики и свечи по трём парам (EURUSD, GBPUSD, USDJPY) на таймфреймах (D1, H4, H1). Дополнительно транслирует значения RSI в реальном времени для мгновенного срабатывания алертов.
- **`MT5CandleSubscriber`** — принимает свечи через ZeroMQ, сохраняет в базу.
- **`MT5TickSubscriber`** — принимает тики в реальном времени. 
- **`AnalyticsController`** — отдаёт REST API.
- **`PostgreSQL (Supabase)`** — хранение истории свечей (2500+ записей).
- **`AnalyticsService`** — рассчитывает тренд (на основе MA20/MA50), находит уровни поддержки и сопротивления. Использует RSI из кэша (real-time) или `ta4j` как резервный расчет, если данных от MT5 еще нет.
- **`AtrService`** — рассчитывает **Средний дневной ATR (за 22 дня)**, а также минимальный и максимальный ATR за этот период.
- **`VolatilityService`** — рассчитывает историческую волатильность по годам и средний месячный ATR для каждого года. 
- **`AlertService & CandleCloseService`** — отправляют уведомления в мессенджер MAX (каскадные RSI-сигналы и алерты о смене тренда только в момент закрытия свечи).

## Эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/analytics/{symbol}/{timeframe}` | RSI + текущая цена + сигнал |
| GET | `/api/analytics/levels/{symbol}/{timeframe} ` | Уровни поддержки и сопротивления |
| GET | `/api/analytics/atr/history/{symbol}` | Статистика волатильности (ATR) по годам |

**Примеры вызова:**
- `GET /api/analytics/EURUSD/D1`
- `GET /api/analytics/levels/EURUSD/H4`
- `GET /api/analytics/atr/history/EURUSD`

### Что работает «под капотом»

- **MT5 на VPS** (Москва) — источник данных, работает 24/7.
- **MQL5-советник** — отправляет тики и свечи через ZeroMQ.
- **Java-бэкенд** — запущен как Windows-служба, автоматически стартует при перезагрузке сервера.
- **Supabase** — облачное хранилище свечей.
- **Интеграция с MAX** — отправка уведомлений о сигналах RSI и смене трендов.

## Как запустить

1. Клонировать репозиторий:
   ```
   git clone https://github.com/ENS21/forex_analyzer.git
   ```
2. Открыть в IntelliJ IDEA.
3. Настроить переменные окружения:
    - `DB_URL` — JDBC-URL базы данных
    - `DB_USERNAME` — имя пользователя
    - `DB_PASSWORD` — пароль
4. Запустить `ForexAnalyzerApplication`.
5. Открыть в браузере:
    - Swagger UI: `http://localhost:8080/swagger-ui.html`
    - API: `http://localhost:8080/api/analytics/EURUSD/D1`

**Примечание:** для получения реальных данных приложению нужен запущенный MQL5-советник, отправляющий свечи через ZeroMQ на порт 5555.
